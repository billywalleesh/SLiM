## The thing to know before you show it

The four sites span **1.26 °C**. Each one warmed by **1.0–1.4 °C** between the two periods.
So on the map's 13.9 °C ramp all eight values fall in a narrow warm band, and the four
squares look similar. That is not a rendering failure — it is the result.

Say it out loud, because it is a point in your favour:

> The difference between my four sites is about the same size as the warming each one has
> already experienced. A spatial comparison alone cannot separate the two. That is why the
> model has to run in time.

If you would rather the four squares looked clearly different, the only honest way is to
state a second scale ("stretched to the range of these four sites") and label it as such.
Do not silently rescale — someone will put this slide next to the map and notice.
