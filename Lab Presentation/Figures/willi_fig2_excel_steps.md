# Rebuilding Willi et al. figure 2 in Excel, with Ne = 500

Both panels are pure arithmetic — no data, no fitting. `willi_fig2.xlsx` already has the
grids built and recalculated; these steps are for the charting, and for rebuilding the
sheets yourself if you'd rather type the formulas.

**Source:** Willi Y, Kristensen TN, Sgrò CM, Weeks AR, Ørsted M, Hoffmann AA (2022).
*Conservation genetics as a management tool: the five best-supported paradigms to assist
the management of threatened species.* PNAS 119(1):e2105076119, figure 2. Both panels are
redrawn there from Crow & Kimura (1970).

---

## The two equations

**Panel A — heterozygosity under drift**

```
H(t) = H0 × (1 − 1/(2·Ne))^t
```

Each generation, drift removes a fraction `1/(2Ne)` of the heterozygosity that is left.
Start at `H0 = 1` and the curve is just that fraction compounding.

**Panel B — a rare allele surviving one bottleneck**

```
P(retained) = 1 − (1 − q′)^(2·Ne)
```

A bottleneck of `Ne` individuals passes on `2Ne` gene copies. The rare allele is lost only
if *every one* of those copies happens to be the common allele — probability `(1 − q′)^(2Ne)`.
One minus that is the chance it survives.

## Panel A — building the sheet

The layout in the workbook:

| | A | B | C | D | E | F | G |
|---|---|---|---|---|---|---|---|
| **4** | Starting heterozygosity, H0 | `1` | | | | | |
| **6** | Ne | `2` | `10` | `50` | `100` | `500` | `1000` |
| **7** | Generation | Ne = 2 | Ne = 10 | Ne = 50 | Ne = 100 | **Ne = 500** | Ne = 1000 |
| **8** | 0 | 1.0000 | … | | | | |

1. Row 6 holds the **numbers**, row 7 the **series names** (`="Ne = "&B6`). Row 7 is what the
   chart legend reads, so it updates itself if you change an Ne.
2. Column A, from row 8: `0, 1, 2, …` down to 200.
3. In **B8**, type:

   ```
   =$B$4*(1-1/(2*B$6))^$A8
   ```

   Then drag right to G8, and drag the whole block down to row 208. The mixed references do
   the work: `B$6` locks onto the Ne row, `$A8` onto the generation column, `$B$4` onto H0.

### The chart

4. Select **A7:G208**.
5. **Insert → Charts → Scatter → Scatter with Smooth Lines** (not "Line" — Line treats the
   x values as categories and will space generation 0 and 200 equally with everything else).
6. Delete the chart title and the gridlines.
7. Horizontal axis: **Bounds** 0 to 200, title `Generations`.
   Vertical axis: **Bounds** 0 to 1, title `Heterozygosity`.
8. Format the **Ne = 500** series: **Line → Solid line**, hex **EB6834**, width **3 pt**.
   Set the other five to grey (**8A8880**), width **1.5 pt**. One line in colour, the rest
   as context — that is the whole design.
9. Delete the legend and label the lines directly instead: **Insert → Text Box**, one per
   curve, placed at its right-hand end. Legends make the reader look back and forth; end
   labels don't.

## What the numbers say

Heterozygosity retained after 100 generations:

| Ne | Retained | Lost |
|---|---|---|
| 2 | 0.0% | 100% |
| 10 | 0.6% | 99.4% |
| 50 | 36.6% | 63.4% |
| 100 | 60.6% | 39.4% |
| **500** | **90.5%** | **9.5%** |
| 1000 | 95.1% | 4.9% |

## One thing to be careful about saying

Adding Ne = 500 to panel A is worth doing — it puts the GBF threshold on the same axes as
the theory. But on the paper's original x range, 500 and 1000 nearly overlap and both look
flat, and that is not a rendering problem. **`1/(2Ne)` is smooth and monotone in Ne, so this
equation has no tipping point — at 500 or anywhere else.**

So the figure does not show *why* 500 was chosen. What it shows is the shape of the trade-off
the threshold sits on: loss is catastrophic at Ne = 10, serious at 50, slow at 500, slightly
slower at 1000. The 500 itself comes from a different argument — the balance between
quantitative genetic variance lost to drift and variance regenerated by mutation
(Franklin 1980) — which is not the equation plotted here.

If you want the curves to separate visibly, extend the x axis rather than rescaling y. The
sheet runs to generation 200 for that reason. At generation 1000, Ne = 500 is down to 37%
and Ne = 1000 to 61%.

And the honest line for the talk, if you want one: *the theory gives you a continuum; the
indicator needs a number; 500 is where the line was drawn.*
